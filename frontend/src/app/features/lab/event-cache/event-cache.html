Ownership

The cache is derived data, so its loss must affect performance—not correctness or recoverability.

Invalidation

Event updates refresh the entry, deletion and reservations evict it, and the following read repopulates from committed database state.

  1. Measure the uncached read before adding Redis.
  2. Choose keys, TTL, serialization, and invalidation owners.
  3. Test miss, hit, update, delete, eviction, and Redis outage.
  4. Compare latency improvement against staleness and operational cost.
