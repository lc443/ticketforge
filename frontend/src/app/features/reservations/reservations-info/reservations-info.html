Gap

My Reservations isn't buildable yet

Reserving tickets works — try it here. But there's no "My Reservations" page, because the backend can't support one yet:

  • POST /api/events/{{ '{' }}eventId{{ '}' }}/reservations exists and works.
  • There's no GET endpoint to list reservations — for anyone.
  • The Reservation entity has no link to a User at all, so even with a list endpoint, there'd be no way to filter it to "yours".

Fixing this means adding a userId column to Reservation, wiring it from the authenticated principal on create, and adding a GET /api/reservations/mine endpoint — real backend/data-model work, not a UI task. Rather than fake a list with data the API can't actually provide, this page says so plainly instead.

For now: each reservation's confirmation is shown once, right after you make it, on the event page.
