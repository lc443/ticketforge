Sprint 20

Kubernetes networking

Trace DNS and Service routing, publish one controlled edge, terminate TLS, and declare least-privilege traffic.

The problem

Pod IPs are disposable and ClusterIP is internal.

Port-forward is a debugging tunnel, not a public endpoint. Publishing every workload would expand the attack surface.

The solution

Separate discovery, routing, and policy.

Services stabilize east-west access; Gateway API owns north-south listeners; HTTPRoute delegates paths; NetworkPolicy constrains allowed flows.

Exercise 5 · TLS boundary

Terminate HTTPS at the Gateway

- name: https
  hostname: ticketforge.example.com
  protocol: HTTPS
  port: 443
  tls:
    mode: Terminate
    certificateRefs:
      - kind: Secret
        name: ticketforge-tls
Terminate

The Gateway presents the public certificate and forwards HTTP inside the cluster.

certificateRefs

References certificate material delivered separately; no private key belongs in Git.

hostname

Limits the listener and route to the intended DNS identity.

Production requirement

Add certificate automation, renewal alerts, an HTTP-to-HTTPS redirect, and an internal encryption decision before claiming end-to-end transport security.
