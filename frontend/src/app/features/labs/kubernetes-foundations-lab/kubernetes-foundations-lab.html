Exercise 3 · configuration boundary

Separate configuration from credentials

ConfigMap

Ports, service DNS names, and other non-sensitive runtime settings.

Secret

Database credentials and JWT signing material, protected with RBAC and external secret management in production.

openssl rand -hex 32

kubectl create secret generic ticketforge-api-secret \
  --namespace ticketforge \
  --from-literal=DB_USERNAME=postgres \
  --from-literal=DB_PASSWORD='<local-password>' \
  --from-literal=JWT_SECRET='<64-character-value>'

kubectl describe secret ticketforge-api-secret \
  --namespace ticketforge
Security boundary

Kubernetes Secret values are base64-encoded, not automatically encrypted. Never commit the local file, print its YAML during normal work, or mistake its resource name for a complete security control.

Exercise 4 · artifact transfer

Load the application image into kind

The Docker Desktop image store and kind node containerd store are separate runtimes.

docker build \
  --file infrastructure/docker/Dockerfile.api \
  --tag ticketforge-api:k8s \
  .

kind load docker-image \
  --name ticketforge \
  ticketforge-api:k8s
--tag

Creates the exact image reference used by the Deployment.

kind load docker-image

Transfers image content into the node's containerd runtime.

imagePullPolicy: IfNotPresent

Uses the loaded local image; otherwise the kubelet tries the registry.

Failure observed

Multi-platform dependency images failed local transfer because Docker's lazy image store lacked referenced content. The kubelet then pulled the correct linux/arm64 variants directly. Diagnose the runtime boundary before changing manifests.

EndpointSlice

Shows the ready Pod IPs selected behind a Service.

port-forward

Creates a temporary local tunnel for development evidence; it is not production ingress.

--watch

Streams changes until you press Ctrl+C.
