# TicketForge Product Requirements

## Problem

Users need a simple way to browse events, reserve tickets, and purchase tickets.

The system must prevent ticket overselling.

---

## User Features

- Register
- Log in
- Browse events
- View event details
- Reserve tickets
- Purchase tickets
- View purchased tickets

---

## Administrator Features

- Create events
- Manage inventory
- View purchases

---

## Non-Functional Requirements

- Prevent ticket overselling
- Support horizontal scaling
- Support asynchronous processing
- Support caching
- Support containerization
- Support Kubernetes deployment
- Support cloud deployment
